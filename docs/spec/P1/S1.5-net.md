# 1.5 Lattice AQFT net

## Human layer
We define the local observable algebras $\mathfrak{A}(I)$ for a region $I \subseteq \mathbb{Z}_L$. It is the $*$-subalgebra generated by $\{c_j, c_j^\dagger \mid j \in I\}$.
**Theorems:**
1. Isotony: $I \subseteq J \implies \mathfrak{A}(I) \subseteq \mathfrak{A}(J)$.
2. Parity: Automorphism $\alpha(c_j) = -c_j$ giving a $\mathbb{Z}_2$-grading.
3. Twisted locality: Disjoint regions commute on even elements and anticommute on odd ones.
4. Local commutativity: The even subnet is purely local.
5. Additivity: $\mathfrak{A}(I \cup J) = \mathfrak{A}(I) \vee \mathfrak{A}(J)$.
6. Translation covariance: A shift operator induces an automorphism matching index shifts.

## Machine layer

def Net (I : Finset (Site L)) : StarSubalgebra C (Module.End C (Fock (Site L)))

## Hazards
- Subalgebras in Lean are bundled. Additivity $\vee$ refers to the supremum in the lattice of subalgebras.
- Twisted locality requires defining the even/odd components rigorously via the parity automorphism.
- $\mathbb{Z}_L$ is a ring; translation covariance is an automorphism of the global algebra, but restricted it maps $\mathfrak{A}(I)$ to $\mathfrak{A}(I+1)$.
