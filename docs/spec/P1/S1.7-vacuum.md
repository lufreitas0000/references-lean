# 1.7 Vacuum, N, normal ordering

## Human layer
We define the Dirac vacuum $\Omega$: a mode $n$ is occupied if and only if $n \le 0$.
The normal-ordered number operator is $\hat{N} = \sum_n (\hat{n}_n - \langle \hat{n}_n \rangle_\Omega)$.
**Theorems:**
1. The particle number of a state $S$ is $N(S) = |S| - L/2$.
2. Explicit definition of normal ordering $\,:\! c_a^\dagger c_b \!:\,$ relative to $\Omega$.
3. $\langle \Omega | \,:\! X \!: | \Omega \rangle = 0$ for bilinears.
4. Sector ground states $|N\rangle_0$ (for $|N| \le L/2$) are mutually orthogonal, normalized, and satisfy $\hat{N}|N\rangle_0 = N|N\rangle_0$.

## Machine layer

## Hazards
- Definition of normal ordering is specific to bilinears initially to avoid full Wick theorems which aren't strictly needed yet.
- The state phase conventions for $|N\rangle_0$ must be rigorously fixed (e.g. applying $c^\dagger$ in a specific order).
- $N(S) = |S| - L/2$ uses integer subtraction, not $\mathbb{N}$-subtraction, to avoid truncation errors when $|S| < L/2$.
