# 1.3 Finite Fourier

## Human layer
We introduce the primitive $L$-th root of unity $\zeta = \exp(2\pi i/L)$ and define the plane waves $e_k(x) = \zeta^{kx}$.
**Theorems:**
1. Orthogonality: $\sum_{x \in \mathbb{Z}_L} \zeta^{(k-k')x} = L \delta_{kk'}$.
2. The discrete Fourier transform (DFT) matrix $U$ is unitary: $U U^\dagger = 1$.
3. Difference operators are diagonalized: $\Delta e_k = (\zeta^k - 1) e_k$ and $\nabla e_k = (1 - \zeta^{-k}) e_k$.

## Machine layer
```spec
def e_k (zeta : C) (k x : Int) : C := pow(zeta, k * x)
theorem orthogonality (L : Nat) (zeta : C) (h_prim : IsPrimitiveRoot zeta L) (k : Int) (h_k : k != 0) (h_mod : k % L != 0) : sum(x in ZMod L, pow(zeta, k * x)) = 0
theorem Delta_e_k (zeta : C) (k : Int) : Delta (e_k zeta k) = fun x => (pow(zeta, k) - 1) * e_k zeta k x
```

## Hazards
- Using actual $\exp(2\pi i/L)$ inside proofs introduces analytic limits. We must strictly use the algebraic `IsPrimitiveRoot` API instead.
- Sign convention in exponent: physics vs math conventions. Must be strictly aligned with Miranda.
- Division by $L$ in the inverse transform needs a field of characteristic zero (e.g. $\mathbb{C}$).
