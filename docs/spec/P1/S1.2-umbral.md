# 1.2 Umbral calculus core

## Human layer
We study the shift operator $E f(x) = f(x+1)$ and the forward/backward difference operators $\Delta = E - 1$, $\nabla = 1 - E^{-1}$ on functions $\mathbb{Z} \to R$ and $\mathbb{Z}_L \to R$.
**Theorems:**
1. $E$ is an algebra automorphism and $E^L = 1$ on $\mathbb{Z}_L \to R$.
2. Leibniz rule: $\Delta(fg) = (\Delta f)g + E(f)\Delta g$.
3. Telescoping sum on $\mathbb{Z}$: $\sum_{a \le x < b} \Delta f(x) = f(b) - f(a)$.
4. Summation by parts: $\sum f \Delta g = - \sum (\nabla f) g$.
5. Newton expansion for $E^n$.
6. Falling factorials property: $\Delta x^{\underline{n}} = n x^{\underline{n-1}}$.
7. Umbral map $\Phi: X^n \mapsto x^{\underline{n}}$ satisfies $\Phi \circ d/dX = \Delta \circ \Phi$.
8. Heisenberg pair: let $\beta f(x) = x f(x-1)$, then $\Delta \beta - \beta \Delta = 1$.
9. Finite-dimensional no-go theorem for Heisenberg pair.

## Machine layer
```spec
def E (f : Int -> R) : Int -> R := fun x => f (x + 1)
def Delta (f : Int -> R) : Int -> R := fun x => f (x + 1) - f x
def Nabla (f : Int -> R) : Int -> R := fun x => f x - f (x - 1)
def beta (f : Int -> R) : Int -> R := fun x => x * f (x - 1)
theorem leibniz (f g : Int -> R) : Delta (fun x => f x * g x) = fun x => Delta f x * g x + E f x * Delta g x
theorem umbral_heisenberg (f : Int -> R) : Delta (beta f) - beta (Delta f) = f
theorem nogo_finite_dim (n : Nat) (h : n > 0) (A B : Matrix (Fin n) (Fin n) K) : A * B - B * A != 1
```

## Hazards
- Ring structure: some properties need commutativity, some need $\mathbb{Q} \subseteq R$ (like $1/n!$ in expansions).
- The Heisenberg pair holds on polynomials or functions on $\mathbb{Z}$, but intrinsically fails on finite domains due to the trace argument.
- Telescoping bounds (e.g. $a \le x < b$) require care with $\mathbb{N}$-subtraction if mapped to $\mathbb{N}$. We use integer indices.
