# 1.9 Umbral boson Fock layer

## Human layer
We build a bosonic Fock space representation algebraically on multivariate polynomials `MvPolynomial (BosonIdx Q) ℂ`. The creation operator $a_m^\dagger$ is multiplication by $X_m$, and $a_m$ is the partial derivative $\partial_m$. We use unnormalized generators $J_m^\dagger = X_m$ and $J_m = m \partial_m$.
**Theorems:**
1. Exact CCR: $[a_m, a_{m'}^\dagger] = \delta_{mm'}$ and $[a_m, a_{m'}] = 0$ as exact identities in `Module.End`.
2. Vacuum functional $\omega_0$ maps a polynomial to its constant coefficient.
3. The number operator $\sum_m X_m \partial_m$ acts as the degree operator (Euler's homogeneous function theorem).
4. On weight-$\le K$ subspaces, nilpotent truncated exponentials $(\sum_m \lambda_m J_m)^{K+1} = 0$, making $\exp_K$ finite and exact.

## Machine layer
```spec
def a_dag (m : BosonIdx Q) : Module.End C (MvPolynomial (BosonIdx Q) C)
def a (m : BosonIdx Q) : Module.End C (MvPolynomial (BosonIdx Q) C) := MvPolynomial.pderiv m
def J_dag (m : BosonIdx Q) : Module.End C (MvPolynomial (BosonIdx Q) C) := a_dag m
def J (m : BosonIdx Q) : Module.End C (MvPolynomial (BosonIdx Q) C) := m * a m
theorem CCR_a_adag (m m' : BosonIdx Q) : a m * a_dag m' - a_dag m' * a m = if m = m' then 1 else 0
theorem nilpotent_exp (K : Nat) (P : MvPolynomial (BosonIdx Q) C) (h : weight P <= K) : pow(sum(m, lambda m * J m), K + 1) P = 0
```

## Hazards
- Using polynomials avoids the domain issues of unbounded operators entirely.
- Unnormalized $J_m$ is used to avoid $\sqrt{m}$ which introduces irrational numbers.
- The degree operator theorem needs Euler's theorem on homogeneous polynomials.
