# 1.4 CAR representation

## Human layer
We specify the canonical anticommutation relations (CAR) for fermions on an abstract index set $\iota$. We define operators $c_i$ and $c_i^\dagger$.
**Theorems:**
1. $\{c_i, c_j^\dagger\} = \delta_{ij}$ and $\{c_i, c_j\} = 0$.
2. Concrete representation on Fock space `Finset ι -> ℂ` via Jordan-Wigner-like signs: a state is described by the occupied modes, and applying $c_i^\dagger$ gives a sign $(-1)^{\#\{k \in S \mid k < i\}}$.
3. We instantiate this for $\iota = \text{Chirality} \times \text{Mode } L$.
4. $c_i^\dagger$ is the adjoint of $c_i$ under the canonical inner product.

## Machine layer
```spec
structure CARRep (I : Type) (V : Type) :=
  (c : I -> Module.End C V)
  (cdag : I -> Module.End C V)
  (anti_c_cdag : forall i j, c i * cdag j + cdag j * c i = if i = j then 1 else 0)
  (anti_c_c : forall i j, c i * c j + c j * c i = 0)

def Fock (I : Type) := Finset I -> C
```

## Hazards
- To define the sign $(-1)^{\#\{k \in S \mid k < i\}}$, we need a strict linear order `[LinearOrder ι]` on the index set.
- We must handle inner products algebraically without topology, as `Fock ι` is finite-dimensional.
- Adjoints require the star-algebra machinery from Mathlib (`StarSubalgebra`).
