# 1.6 Position/momentum fermions, tight-binding

## Human layer
We relate position and momentum fermions via Fourier transform: $c_j = L^{-1/2} \sum_n \zeta^{nj} c_n$.
**Theorems:**
1. The CAR relations hold for $c_j$ exactly because the DFT matrix is unitary.
2. Sum of local densities $\sum_j n_j = \sum_n n_n$.
3. The tight-binding Hamiltonian $H = -t \sum_j (c_j^\dagger c_{j+1} + h.c.)$ can be written in momentum space as $H = \sum_n \varepsilon(n) c_n^\dagger c_n$, with $\varepsilon(n) = -2t\cos(2\pi n/L)$ representing the exact dispersion.
4. Using the umbral layer, $H = t \sum_j c_j^\dagger ((\Delta + \nabla) c)_j - 2t \hat{N}$.

## Hazards
- We avoid `Real.cos` and limits. $\varepsilon(n)$ is formalized algebraically using $(\zeta^n + \zeta^{-n})$.
- We must strictly fix the sign conventions for the Fourier sum using the oracle.
- $c_j$ vs $c_n$ basis changes need the unitarity theorem from `Fourier`.
