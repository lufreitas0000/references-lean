# 1.1 Lattice and index types

## Human layer
We define the physical sites as a periodic lattice $\mathbb{Z}_L$. Momentum modes are restricted to the centered band $\{ n \in \mathbb{Z} \mid -L < 2n \le L \}$. Chirality $\nu \in \{R, L\}$ distinguishes right- and left-movers.
**Theorems:** For an even integer $L$, the cardinality of the mode band is exactly $L$. There is an explicit bijection between the mode band and the site lattice $\mathbb{Z}_L$.

## Machine layer
```spec
def Site (L : Nat) := ZMod L
def Mode (L : Nat) := {n : Int // -L < 2*n /\ 2*n <= L}
inductive Chirality | R | L
theorem card_mode_eq_L (L : Nat) (h : 2 * (L / 2) = L) : Fintype.card (Mode L) = L
def mode_equiv_site (L : Nat) (h : 2 * (L / 2) = L) : Equiv (Mode L) (Site L)
```

## Hazards
- $L$ needs to be strictly positive (`[NeZero L]`) for most site operations.
- `L/2` in $\mathbb{N}$ truncates. We must assume `Even L` as `2 * (L / 2) = L` to prevent truncation mismatch.
- Modes are strict subtypes of $\mathbb{Z}$, not modular integers; no implicit wrap-around modulo $L$ should happen in `Mode L`. Out-of-band reduction must be explicit.
