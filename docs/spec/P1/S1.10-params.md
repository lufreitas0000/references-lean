# 1.10 Parameters, canaries, ledger freeze

## Human layer
We define the parameter structures for the models: `LatticeData` enclosing $(L, \text{Even } L, L > 0)$ and `Window` enclosing $(L, K, N_{max}, Q)$.
**Theorems:**
1. Non-vacuity canaries: For small instances like $L=4, 6$, the budget dimension is strictly greater than 1, and the window conditions are satisfiable.
2. Ledger freeze of assumptions A1–A9.

## Machine layer
```spec
structure LatticeData :=
  (L : Nat)
  (hL : 2 * (L / 2) = L)
  (hNeZero : NeZero L)

structure Window :=
  (L K Nmax Q : Nat)
  (h_valid : L > 0)

theorem canary_L4 : exists (w : Window), w.L = 4
```
