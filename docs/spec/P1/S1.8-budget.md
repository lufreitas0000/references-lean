# 1.8 Energy and budget

## Human layer
We define the momentum $P(S) = \sum_{n \in S} n - \sum_{n \le 0} n$ and the excitation energy $e(S) = P(S) - N(N+1)/2$.
**Theorems:**
1. $e(S) \ge 0$ for all states $S$.
2. $e(S) = 0 \iff S$ is the sector ground state.
3. A deep hole at depth $d$ adds $d$ to the energy $e$.
4. The budget space $K, N_{max}$ is the span of basis states with $e(S) \le K$ and $|N(S)| \le N_{max}$.
5. Energy-shift lemmas specifying how applying $c_n, c_n^\dagger$ transforms $(N, P, e)$.

## Machine layer
```spec
def P_val (S : Finset (Mode L)) : Int := sum(n in S, n) - sum(n in Omega L, n)
def e_val (S : Finset (Mode L)) (N : Int) : Int
axiom e_val_def (S : Finset (Mode L)) (N : Int) : 2 * e_val S N = 2 * P_val S - N * (N + 1)
theorem e_val_nonneg (S : Finset (Mode L)) : e_val S (N_val S) >= 0
theorem e_val_eq_zero_iff (S : Finset (Mode L)) : e_val S (N_val S) = 0 <-> S = sector_ground_state (N_val S)
def Budget (L K Nmax : Nat) : Submodule C (Fock (Mode L))
```

## Hazards
- $N(N+1)/2$ must be done carefully to avoid fractional types (either use integer division since $N(N+1)$ is even, or state as $2e = 2P - N(N+1)$ without division).
- Modifying sets with $c, c^\dagger$ requires handling the presence/absence of elements (decidability).
