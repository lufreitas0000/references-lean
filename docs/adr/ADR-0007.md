# ADR-0007: Interaction

## Context
Defining density-density interactions on a lattice involves choices around normal ordering and point-splitting. Incorrect choices can lead to ambiguities or infinite limits when operators overlap.

## Decision
We will define the interaction Hamiltonian $H_{int}$ using smooth, band-limited densities (as outlined in draft §3.7). This provides an explicitly regularized interaction on the lattice.

## Consequences
*   Resolves normal ordering ambiguities natively.
*   Ensures that interactions remain finite algebraic sums over the lattice band without requiring singular limits.
