# ADR-0003: Normalization

## Context
Bosonic creation and annihilation operators derived from fermion densities traditionally use a normalization factor involving $\sqrt{m}$. In a strictly algebraic Lean formalization without real analysis, arbitrary square roots of integers introduce complex types and definitional equality problems.

## Decision
We will use unnormalized density modes $J_m = \rho(-m)$ throughout the Core mathematical layers, which satisfy the commutation relation $[J_m, J_m^\dagger] = m$. The standard normalized bosons $b_m = J_m/\sqrt{m}$ will only be defined in a high-level adapter/interface layer used for continuum interpretation.

## Consequences
*   The core algebra remains purely rational/integer-based, operating without `Real.sqrt`.
*   Equations will carry explicit factors of $m$, preventing analytical ambiguities.
