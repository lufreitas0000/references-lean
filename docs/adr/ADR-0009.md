# ADR-0009: Correlator machinery

## Context
Evaluating exact correlation functions of fields is the main theorem objective. Standard approaches require full inner-product spaces and continuous Fourier transforms, which introduces analytical complexity.

## Decision
We will calculate correlators using formal power series and twisted group algebras for the quasi-free state. Crucially, we will *not* require positivity of the state to prove formal algebraic identities.

## Consequences
*   The exact correlators (including $g$-scaling behavior) can be proven as purely algebraic identities.
*   Bypasses Gaussian integration or topological limits in Lean.
