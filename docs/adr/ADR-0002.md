# ADR-0002: Index types

## Context
We need precise, robust index types for lattice sites and momentum modes in order to avoid edge-case errors like out-of-bounds access or division truncations in $\mathbb{N}$.

## Decision
We will use `ZMod L` for lattice sites, representing the periodic nature of the spatial lattice. For momentum modes, we will use a $\mathbb{Z}$-subtype band `Mode L := {n : ℤ // -L < 2*n ∧ 2*n ≤ L}`. We will also construct an explicit `Equiv` between `Mode L` and `ZMod L`.

## Consequences
*   Wrap-around and periodic boundary conditions are handled natively by `ZMod L`.
*   We completely avoid $\mathbb{N}$ division issues (like `L/2` truncation) by stating constraints as `-L < 2*n ∧ 2*n ≤ L`.
*   Forces explicit casts and equivalence maps, which increases verbosity slightly but guarantees mathematical exactness.
