# ADR-0008: Bogoliubov parametrization

## Context
The Bogoliubov transformation involves hyperbolic rotations. Standard representations use angles and `cosh`/`sinh` functions, which invoke real analysis and transcendental functions.

## Decision
We will parametrize the Bogoliubov transformation purely algebraically using pairs of values $(c, s)$ subject to the constraint $c^2 - s^2 = 1$.

## Consequences
*   We completely avoid `Real.cosh` and `Real.sinh`, keeping the parametrization inside polynomial/algebraic structures over $\mathbb{C}$.
*   Proofs rely strictly on polynomial identities rather than trigonometric/hyperbolic identities.
