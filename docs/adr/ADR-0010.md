# ADR-0010: Junk-value policy

## Context
Functions in Lean like division (`/`) or subtraction (`-`) over $\mathbb{N}$ return "junk values" (e.g., $3 - 5 = 0$) when inputs violate expected domain constraints, leading to mathematically true but physically meaningless theorems.

## Decision
We strictly enforce the junk-value policy from roadmap §6.4. We will avoid $\mathbb{N}$ subtraction and division in statements (e.g., writing $2*h = L$ instead of $L/2$). We will use explicit positivity hypotheses for division and square roots (in the adapters), and explicitly demand `NeZero L` whenever `ZMod L` is used.

## Consequences
*   Theorems remain strictly physical and mathematically robust.
*   Statements might carry more hypotheses, but they will not hide edge cases behind Lean's total functions.
